# ☕ Estudos-Java

Repositório criado para registrar minha evolução nos estudos de **Java** e **Programação Orientada a Objetos (POO)**.

Aqui estão exercícios, testes, desafios e pequenos projetos desenvolvidos durante minha jornada de aprendizado, começando pelos fundamentos da linguagem e avançando gradualmente para conceitos de POO.

> 🎯 **Objetivo:** construir uma base sólida em Java, desenvolver minha lógica de programação e evoluir gradualmente para o desenvolvimento **backend**.

## 📂 Organização do projeto

Os estudos estão separados por etapa de aprendizado:

```text
Estudos-Java/
├── src/
│   ├── JavaBasico/
│   │   └── Exercícios e estudos dos fundamentos de Java
│   │
│   └── JavaPoo/
│       └── Exercícios e estudos de Programação Orientada a Objetos
│
└── .gitignore
```

### `JavaBasico/`

Contém exercícios e experimentos relacionados aos fundamentos da linguagem Java, lógica de programação, estruturas de controle, arrays, métodos e outros conceitos iniciais.

### `JavaPoo/`

Contém os estudos relacionados à **Programação Orientada a Objetos**, incluindo criação de classes, objetos, atributos, métodos e outros conceitos que serão adicionados conforme avanço nos estudos.
